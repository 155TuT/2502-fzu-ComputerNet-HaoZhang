## 一、选择题（每小题 2 分，共 30 分）

### 1. 以下（ ）术语描述了物理层上传输的基本单位？
A. 比特  
B. 帧  
C. 包  
D. 码元  
* **正确答案**：**A**  
* **解析**：物理层传输的最小基本单位是比特（Bit）。数据链路层是帧（Frame），网络层是分组/包（Packet）。

### 2. 以下哪种传输介质抗电磁干扰性最好？（ ）
A. 双绞线  
B. 同轴电缆

D. 无线电波  
* **正确答案**：**C**  
* **解析**：光纤利用光信号在玻璃纤维中传输，不受任何外界电磁干扰。

### 3. 在 CSMA/CD 协议中，CD 表示（ ）。
A. 载波侦听  
B. 碰撞检测

D. 碰撞避免和检测  
* **正确答案**：**B**

## 三、简答题（每小题 4 分，共 20 分）

### 1. 简述什么是协议。（4 分）
* **答**：
  网络协议（简称协议）是为进行网络中的数据交换而建立的规则、标准或约定。协议规定了通信双方应当“怎么讲”、“讲什么”和“讲话的顺序”。网络协议主要由以下三个要素组成：
  1. **语法**：数据与控制信息的结构或格式。
  2. **语义**：需要发出何种控制信息，完成何种动作以及做出何种响应。
  3. **同步（定时）**：事件实现顺序的详细说明。

### 2. 简述 ARP 协议及其原理。（4 分）
* **答**：
  ARP（地址解析协议）用于将网络层的 IP 地址动态解析为数据链路层的 MAC 地址。其工作原理为：
  1. 当主机需要向本局域网上的另一台主机发送 IP 数据报时，先在自己的 ARP 缓存表中查询目标 IP 对应的 MAC 地址。
  2. 若查到，则直接封装入 MAC 帧发送。
  3. 若未查到，主机发送一个 **ARP 请求报文**，源 MAC 为单播，目的 MAC 为**广播地址**（全 F）。局域网内所有主机都会收到此请求。
  4. 只有目标 IP 地址相符的主机才会收下该请求，并向源主机发送一个**单播的 ARP 响应报文**，告知自己的 MAC 地址。
  5. 源主机收到后，将该 IP-MAC 映射写入 ARP 缓存表，并完成帧的发送。

### 3. 简述网桥（或交换机）的自学习过程。（4 分）
* **答**：
  以太网交换机（网桥）通过自学习算法自动建立和维护其 MAC 地址转发表（端口-地址表）：
  1. 刚加电启动时，交换机内部的 MAC 地址表是空白的。
  2. 当交换机从某个端口 $P$ 接收到一个帧时，它会读取该帧的**源 MAC 地址** $S$，并在 MAC 地址表中查找是否有关于 $S$ 的记录。如果没有，则把 $(S, P, \text{当前时间})$ 记录到表中。这就是**源地址自学习**。
  3. 接着，它读取该帧的**目的 MAC 地址** $D$，并在表中查找。
     * 若表中已有关于 $D$ 且对应端口为 $Q$ 的记录（且 $Q \ne P$），则将帧转发到端口 $Q$。
     * 若记录的端口就是 $P$，则丢弃该帧（过滤）。
     * 若表中没有关于 $D$ 的记录，则向除 $P$ 以外的所有端口广播（泛洪）该帧。

### 4. 简述 TCP 连接的三次握手机制。（4 分）
* **答**：
  TCP 建立连接需要进行三次握手，过程如下：
  1. **第一次握手**：客户端向服务器发送连接请求报文段，首部中的同步位 $SYN=1$，同时选择一个初始序号 $seq=x$。客户端进入 `SYN-SENT` 状态。
  2. **第二次握手**：服务器收到连接请求后，如果同意建立连接，向客户端发送确认。确认报文段中 $SYN=1, ACK=1$，确认号为 $ack=x+1$，同时自己选择一个初始序号 $seq=y$。服务器进入 `SYN-RCVD` 状态。
  3. **第三次握手**：客户端收到确认后，向服务器给出确认，确认报文段中 $ACK=1$，确认号为 $ack=y+1$，自己的序号为 $seq=x+1$。此报文段可以携带数据，客户端和服务器随后均进入 `ESTABLISHED` 状态。

### 5. 简述什么是 DNS。（4 分）
* **答**：
  DNS（域名系统）是因特网使用的一种分布式数据库系统，用来将便于人类记忆的主机域名（例如 `www.fzu.edu.cn`）动态翻译为便于计算机处理的二进制 IP 地址（例如 `104.207.153.254`）。它工作在应用层，底层使用 UDP 协议进行传输（端口号 53），是因特网的一项核心基础服务。

## 四、计算题（共 30 分）

### 1. （共 5 分）在下列条件下比较电路交换和分组交换。要传送的报文共 $x$ 比特。源点到终点共经过 3 段链路，每段链路的传播时延为 $2\text{ s}$，数据率为 $b\text{ bps}$。电路交换时电路的建立时间为 $5\text{ s}$。在分组交换时分组长度为 $512\text{ bits}$，且各结点的排队等待时间可忽略不计。问在怎样的条件下，分组交换的时延比电路交换短？

* **解**：
  1. **电路交换时延 $T_{\text{circuit}}$**：
     $$T_{\text{circuit}} = \text{建立时间} + \text{总传播时延} + \text{报文发送时延} = 5 + (3 \times 2) + \frac{x}{b} = 11 + \frac{x}{b} \text{ 秒}$$
  2. **分组交换时延 $T_{\text{packet}}$**：
     本题中各节点的排队时延忽略，且每个分组在传输时延上可忽略（按官方答案简化模型计算：发送所有分组的总传输时间为 $x/b$ 砂）。
     $$T_{\text{packet}} = \text{总传播时延} + \text{发送总时间} = (3 \times 2) + \frac{x}{b} = 6 + \frac{x}{b} \text{ 秒}$$
  3. **时延对比条件**：
     $$T_{\text{packet}} < T_{\text{circuit}} \implies 6 + \frac{x}{b} < 11 + \frac{x}{b}$$
     该不等式在简化模型下对于任何合理的 $x$ 和 $b$ 恒成立。
     *(注：若考虑标准的路由器存储转发串行时延，分组交换还要加上 2 次中间路由器转发一个分组的传输时延 $2 \times \frac{512}{b}$。即 $6 + \frac{x}{b} + \frac{1024}{b} < 11 + \frac{x}{b} \implies \frac{1024}{b} < 5 \implies b > 204.8\text{ bps}$。考场上答出官方的简化模型 $x < 5b$（假设发送时延不计入电路交换，或者其他简易推导模型）或标准模型的 $b > 204.8\text{ bps}$ 均可得满分。)*

### 2. （共 4 分）设信号脉冲周期为 $0.005$ 秒，脉冲信号有效值状态个数为 3。如果要用二进制代码表示上述信号，一个脉冲信号需要用多少位二进制代码表示？其数据传输率是多少？

* **解**：
  1. **二进制代码位数 $n$**：
     状态个数为 3，要用二进制完整表示，需要满足 $2^n \ge 3$ 的最小正整数 $n$。
     $$2^1 < 3 \le 2^2 \implies n = 2 \text{ 位}$$
     所以一个脉冲信号需要用 **$2$ 位** 二进制代码表示。
  2. **波特率（码元速率） $B$**：
     $$B = \frac{1}{T} = \frac{1}{0.005} = 200 \text{ Baud}$$
  3. **数据传输率（比特率） $C$**：
     $$C = B \times n = 200 \text{ Baud} \times 2 \text{ bits/Baud} = 400 \text{ bps}$$

### 3. （共 5 分）要发送的数据为 $11011$，若采用的 CRC 生成多项式是 $P(X) = X^3 + X^2 + 1$，试求冗余码。若数据在传输过程中最后一位 1 变成了 0，问接收方能否发现，写出计算过程。

* **解**：
  1. **多项式转二进制**：
     $P(X) = X^3 + X^2 + 1 \to G = 1101$。阶数 $n=3$。
  2. **加 0 并进行模 2 除法**：
     数据后补 3 个 0，得到 $11011000$。
     用 $11011000$ 模 2 除以 $1101$：
     ```txt
               10001
        1101 / 11011000
               1101
               ----
                000100  (余数不足，商0，落下一位)
                  1000
                  1101
                  ----
                   101  (余数为 101)
     ```
     计算得出余数 $R = 001$（注意：必须补足到 $n=3$ 位）。
     所以冗余码为 **$001$**。实际发送数据为 $11011001$。
  3. **差错校验**：
     若最后一位 1 变成 0，接收方收到的数据为 $11011000$。
     接收方用 $11011000$ 模 2 除以生成多项式 $1101$，求得余数为 $001$。
     因为余数 $R = 001 \ne 0$，说明传输过程中发生了差错，接收方可以发现该错误并丢弃该帧。

### 4. （共 8 分）设某路由器的路由表如表 1 所示。
**表 1 路由表**
| 目的网络 | 子网掩码 | 下一跳 |
| :--- | :--- | :--- |
| `205.10.3.0` | `255.255.255.128` | 接口 0 |
| `205.10.3.128` | `255.255.255.128` | 接口 1 |
| `205.10.5.128` | `255.255.255.128` | R2 |
| `59.70.142.128` | `255.255.255.192` | R3 |
| `* (默认)` | `-` | R4 |

现路由器共收到 5 个分组，其目的地址如下。分别计算下一跳（要求写出计算过程和结果）。
**(1) `205.10.3.160`**  
**(2) `205.10.5.3`**  
**(3) `59.70.142.129`**  
**(4) `59.70.142.8`**

* **解**：
  * **(1) 目的地址 `205.10.3.160`**：
    * 与第二个子网掩码 `255.255.255.128` 按位与：`160 & 128 = 128`，匹配网络 `205.10.3.128`。
    * 结果：下一跳为 **接口 1**。
  * **(2) 目的地址 `205.10.5.3`**：
    * 与表中任何特定网络掩码按位与，均无法匹配对应的网络号（例如 `3 & 128 = 0` $\ne 128$）。
    * 结果：匹配默认路由，下一跳为 **R4**。
  * **(3) 目的地址 `59.70.142.129`**：
    * 与掩码 `255.255.255.192` 按位与：`129 & 192 = 128`（$129 = 10000001_2$，$192 = 11000000_2$，按位与结果是 $10000000_2 = 128$）。匹配网络 `59.70.142.128`。
    * 结果：下一跳为 **R3**。
  * **(4) 目的地址 `59.70.142.8`**：
    * 与各掩码相与均不匹配特定网络。
    * 结果：匹配默认路由，下一跳为 **R4**。
